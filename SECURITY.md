# Güvenlik politikası

Bu depo yalnızca genel mimari ve kurulum yaklaşımı içerir. Lütfen issue, pull request, ekran görüntüsü veya log içinde aşağıdakileri paylaşmayın:

- Gerçek alan adları ve genel IP adresleri
- Parolalar, API anahtarları, DKIM özel anahtarları ve sertifika özel anahtarları
- Roundcube uygulama gizli anahtarı, veritabanı parolaları veya router yönetim bilgileri
- Tam posta kutusu adresleri, kullanıcı verileri veya ham mail günlükleri

Bir güvenlik sorunu fark ederseniz, ayrıntıyı herkese açık issue olarak paylaşmak yerine depo sahibine GitHub üzerinden özel iletişim kanalı isteği gönderin. Sorun doğrulanana kadar istismar adımlarını yayımlamayın.

Bu rehberdeki ayarları uygulamadan önce kendi ağınıza ve servis sağlayıcınızın koşullarına göre gözden geçirin.
